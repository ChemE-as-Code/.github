# ChemE-as-Code organization profile

GitHub shows `profile/README.md` of this public repository, named `.github`, on the
[ChemE-as-Code organization page](https://github.com/ChemE-as-Code).

- `profile/README.md`: the profile text.
- `profile/assets/`: the banner (the brand card of cheme-as-code.org), the 3D view of the ammonia
  case study and the contributor photos. They are kept here so that the profile does not depend on
  other repositories.

The organization's display name, description, URL and location are set in its settings
(GitHub → ChemE-as-Code → Settings → General → Profile).
